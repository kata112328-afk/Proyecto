

# FRONTEND BRAINBRO

Esta carpeta contiene la interfaz visual del proyecto BrainBro, desarrollada
para mostrar las diferentes ventanas y secciones de la aplicación educativa.
Los datos mostrados son simulados (borrador).

## Tecnologías utilizadas
- **HTML5:** estructura de las páginas.
- **CSS3:** diseño, colores y estilos visuales.
- **JavaScript:** interacciones y elementos dinámicos de la interfaz.
- **Google Fonts:** tipografía Work Sans (requiere conexión a internet).

## Organización de carpetas
- **html:** contiene la página principal (index.html).
- **js:** app.js (funcionamiento de la interfaz) y data.js (datos de ejemplo).
- **style:** contiene los estilos CSS.
- **imagen:** contiene el logo y las imágenes utilizadas.

## Cómo abrir el proyecto
1. Descargar o clonar el repositorio.
2. Abrir la carpeta web Diseño.
3. Ingresar a la carpeta html.
4. Abrir el archivo index.html en Google Chrome o Microsoft Edge.
