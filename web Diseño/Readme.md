
# BRAINBRO

BrainBro es una aplicación educativa diseñada para fortalecer el aprendizaje de los estudiantes mediante actividades, cuestionarios y seguimiento de su progreso académico.

# FRONTEND BRAINBRO

Esta carpeta contiene la interfaz visual del proyecto BrainBro, desarrollada para mostrar las diferentes ventanas y secciones de la aplicación educativa.

## Tecnologías utilizadas

- **HTML5:** estructura de las páginas.
- **CSS3:** diseño, colores y estilos visuales.
- **JavaScript:** interacciones y elementos dinámicos de la interfaz.

## Organización de carpetas

- **html:** contiene las páginas HTML.
- **js:** contiene los archivos JavaScript.
- **style:** contiene los estilos CSS.
- **imagen:** contiene el logo y las imágenes utilizadas.

## Cómo abrir el proyecto

1. Descargar o clonar el repositorio.
2. Abrir la carpeta web Diseño.
3. Ingresar a la carpeta html.
4. Abrir el archivo index.html en Google Chrome o Microsoft Edge.
